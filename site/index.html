GET STARTED

はじめての設定

  1. APKをインストール

    ダウンロードしたAPKを開きます。必要な場合だけ、ブラウザーの「この提供元のアプリを許可」をONにしてください。

  2. 権限をONにする

    アプリの「アクセシビリティ権限の設定」から、回答ザンギの使用をONにします。

  3. スタートでフロートを表示

    小さな操作ボタンが画面上に出ます。上部をドラッグして、LINEのボタンと重ならない場所へ移動できます。

  4. LINEで超良問ドリルを開き、▶再生

    今表示している画面から始めます。画像だけの「開始」はLINEで1回押してください。本人確認が済むと、初回登録や「もう一度挑戦する」「問題を見る」も自動で進みます。止めるには■停止。第5問ではフロートの答えを見て、本人が数字を入力・送信します。

QUICK HELP

迷ったらここを確認

権限をONにできない

Androidの設定 → アプリ → 回答ザンギ → 右上の︙ → 「制限付き設定を許可」。その後、ユーザー補助設定を開き直します。端末により名称が異なります。

前回の回答記録が残っている

▶再生すると現在画面を確認します。前回と別の未回答問題や再挑戦画面なら自動で進みます。同じ未確認問題の場合は、二重回答を防ぐため結果を待ちます。

要確認で止まった

認識した問題と答え、エラー履歴を確認してください。未知の問題、曖昧な条件、回答ボタンが出ない場合は誤回答を避けて停止します。自動で再送しません。

初回の参加登録は？

登録画面から再生すると自動で進みます。既存情報の「変更する」は選びません。都道府県・高校は見えている専用選択肢からランダムに選び、スクロールしません。生年・性別・規約同意では一時停止します。本人がLINEで選択・確認した後、▶再生で続行してください。既に問題画面なら登録操作をスキップします。登録操作は実機未検証で、画面を確認できない場合は停止します。

複製LINEでも使える？

標準LINEとjp.naver.line系列の複製LINEを、対象トーク名とLINEの画面構造を併せて自動認識します。package名の手入力は不要です。切替後は超良問ドリルのトークで▶再生してください。別packageの仮想化アプリや要素を公開しない複製方式は対応できず停止します。

友人にも配布できる？

この署名済みAPKを各端末にインストールできます。端末連携や管理サーバーは不要です。最初は1台で確認してください。

上書き更新は？

後続版のAPKを開いて更新してください。同じアプリの署名を維持します。アプリを削除すると端末内の設定や履歴は失われます。

形式・条件・丸め方法を読み取れない場合は、数字を推測して入力しません。フロートに表示した答えは本人が入力・送信してください。アプリ内の「計算エンジンで問題文を確認」でも試せます。
