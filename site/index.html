code31 · 自動回答と入力テスト

自動送信まで進むには「第5問・入力テスト設定」をOFFにして通常の▶再生を押してください。||で一時停止すると同じ位置が内向き矢印に変わります。フロートの大きさは固定のまま、▶で再開、×で閉じます。ONでは48dpのまま「試験」からメニューを開き、再生1〜3の入力だけを行い、送信しません。更新前の設定は引き継がれます。

  1. いつもの再生で第5問まで進む

    答えがフロートに表示されます。自動回答できなければ、答えを残して停止します。

  2. アプリで「第5問・入力テスト設定」をON

    通常の自動進行・送信を停止します。LINEに戻り、回答方法の案内と第5問を表示してフロートの「試験」→「問題・答えを確認」で確認してください。

  3. 空の入力欄で「再生1」「再生2」「再生3」を試す

    1＝直接入力、2＝入力欄を選択後に入力、3＝貼り付け。数字が入ったら手動で消してから次へ。テストは入力だけで送信しません。問題確認の有効期限は2分です。

  4. 「診断コピー」で結果を共有

    本文を含まない候補属性・停止段階・読み戻し結果をコピーできます。アプリの「入力診断を表示・コピー」からも操作できます。通常再生に戻すときはテスト設定をOFFにしてください。

再生3は元のクリップボードを退避できる場合だけ実行し、元に戻す処理を行います。権限制限などで試せない場合は理由を表示します。初回登録の本人情報・既知の規約同意の自動操作は、引き続き端末ごとの事前承認設定に従います。

GET STARTED

はじめての設定

  1. APKをインストール

    ダウンロードしたAPKを開きます。必要な場合だけ、ブラウザーの「この提供元のアプリを許可」をONにしてください。

  2. 権限をONにする

    アプリの「アクセシビリティ権限の設定」から、怪盗ザンギの使用をONにします。

  3. スタートでフロートを表示

    小さな操作ボタンが画面上に出ます。上部をドラッグして、LINEのボタンと重ならない場所へ移動できます。

  4. LINEで超良問ドリルを開き、▶再生

    今表示している画面から始めます。開始前のリッチメニューでは「開始」を押し、メニューを閉じて進みます。本人確認が済むと、初回登録や「もう一度挑戦する」「問題を見る」も自動で進みます。止めるには||を押します。停止後は内向き矢印で横長表示に戻せます。第5問は自動入力・送信し、できない場合は答えを残して停止します。

QUICK HELP

迷ったらここを確認

権限をONにできない

Androidの設定 → アプリ → 怪盗ザンギ → 右上の︙ → 「制限付き設定を許可」。その後、ユーザー補助設定を開き直します。端末により名称が異なります。

前回の回答記録が残っている

▶再生すると現在画面を確認します。前回と別の未回答問題や再挑戦画面なら自動で進みます。同じ未確認問題の場合は、二重回答を防ぐため結果を待ちます。

要確認で止まった

認識した問題と答え、エラー履歴を確認してください。未知の問題、曖昧な条件、回答ボタンが出ない場合は誤回答を避けて停止します。自動で再送しません。

初回の参加登録は？

登録画面から再生すると自動で進みます。既存情報の「変更する」は選びません。都道府県・高校は見えている専用選択肢からランダムに選び、スクロールしません。生年・性別・規約同意では一時停止します。本人がLINEで選択・確認した後、▶再生で続行してください。既に問題画面なら登録操作をスキップします。画面を確認できない場合は停止します。

複製LINEでも使える？

標準LINEとjp.naver.line系列の複製LINEを、対象トーク名とLINEの画面構造を併せて自動認識します。package名の手入力は不要です。切替後は超良問ドリルのトークで▶再生してください。別packageの仮想化アプリや要素を公開しない複製方式は対応できず停止します。

友人にも配布できる？

この署名済みAPKを各端末にインストールできます。端末連携や管理サーバーは不要です。最初は1台で確認してください。

上書き更新は？

後続版のAPKを開いて更新してください。同じアプリの署名を維持します。アプリを削除すると端末内の設定や履歴は失われます。
