GET STARTED

はじめての設定

  1. APKをインストール

    ダウンロードしたAPKを開きます。必要な場合だけ、ブラウザーの「この提供元のアプリを許可」をONにしてください。

  2. 権限をONにする

    アプリの「アクセシビリティ権限の設定」から、回答ザンギの使用をONにします。

  3. スタートでフロートを表示

    小さな操作ボタンが画面上に出ます。上部をドラッグして、LINEのボタンと重ならない場所へ移動できます。

  4. LINEで超良問ドリルを開き、▶再生

    今表示している画面から始めます。初回登録や「もう一度挑戦する」「問題を見る」も自動で進みます。止めるには■停止。完了時は待機に戻ります。

QUICK HELP

迷ったらここを確認

権限をONにできない

Androidの設定 → アプリ → 回答ザンギ → 右上の︙ → 「制限付き設定を許可」。その後、ユーザー補助設定を開き直します。端末により名称が異なります。

前回の回答記録が残っている

▶再生すると現在画面を確認します。前回と別の未回答問題や再挑戦画面なら自動で進みます。同じ未確認問題の場合は、二重回答を防ぐため結果を待ちます。

要確認で止まった

認識した問題と答え、エラー履歴を確認してください。未知の問題、曖昧な条件、回答ボタンが出ない場合は誤回答を避けて停止します。自動で再送しません。

初回の参加登録は？

登録画面から再生すると自動で進みます。既存情報の「変更する」は選びません。新規項目は表示された専用選択肢からランダムに選び、参加規約に同意して登録します。既に問題画面なら登録操作をスキップします。登録操作は実機未検証で、画面を確認できない場合は停止します。

複製LINEでも使える？

標準LINEと資料で確認した複製版を初期許可しています。別の複製版は「対応するLINEの設定」で正確なpackage名を登録してください。すべての複製版の動作は未検証です。

友人にも配布できる？

この署名済みAPKを各端末にインストールできます。端末連携や管理サーバーは不要です。最初は1台で確認してください。

上書き更新は？

後続版のAPKを開いて更新してください。同じアプリの署名を維持します。アプリを削除すると端末内の設定や履歴は失われます。

ON-DEVICE ENGINE

数字が変わっても、条件から計算。

三角形面積が最大になる辺
等差数列区間の和・超える項
両端の並び同じ／異なる競技
倍数両方・一方・どちらでもない
ボクシング差と約数・互いに素

形式・条件・丸め方法を読み取れない場合は、数字を推測して入力しません。アプリ内の「計算エンジンで問題文を確認」でも試せます。

データの扱い

アプリにインターネット通信権限はありません。LINEの認証情報や会話内容を外部へ送信せず、認識した問題・回答・エラー履歴をこの端末だけに保存します。

通常のLINEメッセージ送信ボタンは操作しません。画面ロック、別画面、未知の問題で停止します。UI要素が取れない場合のOCRはこの版では未搭載です。
