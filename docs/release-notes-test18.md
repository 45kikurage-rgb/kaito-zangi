# code18 自動進行改善テスト版

2026-10-13 / versionName 0.1.18-test18 / package jp.kossacktouch.app。
既存code15・過去APKは保全し、別枠のテスト配布を更新します。

- 要素認識を1秒から0.5秒へ。2回の一致確認は維持。
- 要素未検出時の探索を最大3往復から6往復へ。従来の連続未検出テストでは約13秒で終了していた探索を26秒まで継続。上方向は画面高さ約10%、下方向は従来の距離。最後のスライド後も期限まで再取得します。0.5秒周期の模擬試験では26秒内に52回確認します（実機の描画・走査時間により変動）。
- 問題／進行ボタン待ち60→120秒、入力欄12→24秒、読み戻し15→30秒、送信ボタン18→36秒、クーポン操作ボタン45→90秒、表示確認35→70秒。画面探索の26秒上限や問題期限240秒など、先に到達する条件で停止します。送信反映待ち90→180秒、再送はしません。
- code17の実機ログで確認された `chat_ui_message_edit` と親要素を通常運転でも認識。IME座標は使わずACTION_SET_TEXTで入力し、完全一致を読み戻してから送信します。
- 入力欄表示前の待機とキーボードを開いた記録を分離。2回確認を待つ間に開く操作が抑止される不具合を修正。
- 第5問の送信後、問題文が画面から消えても、送信記録と正解／クーポン表示を照合して「クーポンをゲットする」へ進行。取得ボタンや送信は結果不明でも繰り返しません。
- 送信候補のID・属性と送信／クーポン操作結果を診断へ追加。下書き・会話本文は記録しません。

## 使い方

1. アンインストールせず、code18 APKで上書き更新してください。
2. 自動送信まで試す場合は、アプリの「第5問・入力テスト」をOFFにしてください。設定は更新前の状態を保持します。再生1〜3は引き続き入力のみで送信しません。
3. 超良問ドリルで通常の▶再生。答え表示→数字入力→送信→「クーポンをゲットする」の順を確認してください。
4. 失敗時は表示した答えと最後の案内に従い、診断をコピーしてください。送信結果が不明なときは重複送信しないでください。

## 検証の区別

ユーザー提供code17ログではNothing/A015・Android16・複製LINEで直接入力と読み戻し一致を確認。ユーザーは初回アンケートから最終問題まで到達したと報告。写真には5問正解とクーポン取得ボタンが写っていますが、アプリの自動送信成功の証明とは扱いません。
code18の実機上書き、設定保持、自動送信、クーポン押下、他機種での完走は未確認です。
