# 怪盗ザンギ code17 入力診断テスト版

- 初回説明の「5問連続正解」をクリアと誤判定しないよう、結果文とクーポン専用ボタンを判定する。
- 導入説明の認識済み二択は右を優先。「初めてだけど頑張ります！」と高校選択前の「わかった！」に対応。登録確認の「変更する」は選ばない。
- 第5問は計算した答えをフロートに先に表示。自動入力・送信ができない場合も答えを残して手動操作を案内。送信操作後に結果が不明なら再送を案内しない。
- アプリの「第5問・入力テスト設定」をONにすると通常再生・自動送信を停止。フロートの「再生1＝直接入力」「再生2＝選択後に直接入力」「再生3＝貼り付け」を個別に試せる。各回入力欄は空にする。入力後の自動消去は行わない。
- テストの前に、回答方法の案内と第5問を表示し▶で確認する。有効期限2分。LINE/package/window/問題が変わった場合や問題が読めない場合は操作しない。座標タップ・独自IMEは使用しない。
- テストの入力候補は従来のLINE入力欄を優先。見つからなければ同じLINEの問題文より下のnative編集要素を検査し、候補1個・空欄の場合のみ試す。この診断用の候補拡張は通常の自動送信には適用しない。
- 再生3はPASTEとフォーカスを確認し、元クリップボードを読み取れる場合だけ一時変更。復元時に他の内容へ変わっていれば上書きしない。端末の権限制限で元内容を取得できない場合は試行せず理由を表示。
- S1〜S6の段階、入力候補数・属性・action ID・window・端末/LINE版、操作戻り値、200/600msの読み戻し一致とtextChangedイベント有無を端末内に記録。下書き/会話/ヒント/クリップボードの本文は診断へ記録しない。テストはS7送信へ進まない。
- 「診断コピー」またはアプリの「入力診断を表示・コピー」から本人が共有できる。診断コピー操作はクリップボードを診断文に置き換える。

既存code15・code16のAPKと正答データ・署名鍵を保全。package、設定と履歴の保存先を維持。上方向10%・下方向の従来スワイプを維持。

ソフトウェア回帰チェック2,549件・Android35向けコンパイルに合格。正式署名・公開証跡は docs/verification-diag17.md に追記する。実機の上書き更新・設定保持・アンケート完走・各方式の入力成功・自動送信は未確認。
