# code19 フロート・クーポン改善テスト版

2026-10-13 / versionName 0.1.19-test19 / versionCode19。

- フロートの文字サイズを1.5倍へ（本文14→21sp、タイトル15→22.5sp、再生20→30sp）。長い案内はフロート内でスクロール可能。
- 「▶ 再生」「|| 停止」「× 閉じる」を独立。停止しても答え・状態・フロートを残し、▶で現在画面から再開。実行中の▶は無効にして誤解を防ぐ。停止／再開前の古い非同期コールバックは新しい操作へ影響させない。
- フロートの横幅だけでスライド不能と判定していた不具合を修正。フロートとIMEを除いた連続した縦範囲を探し、空いている範囲で上下探索。遮蔽物がない場合は上約10%・下従来距離を維持。空き範囲が足りなければ探索期限まで再確認。
- 「クーポンを表示する」が最新クーポンカード内の独立した文字要素として取得できる場合に対応。既知IDだけに限定せず、正確な文言・カードの文脈・一意性・表示範囲を照合。クリック可能な要素を優先し、非クリック要素なら再取得・照合した文字要素の中央を1回タップする。画像から固定座標を決める方式ではない。
- 表示リンクがフロートと重なればフロートを退避して再確認。表示リンクのID・属性・候補の有無を診断に追加。案内文とリンクが1つの要素にまとめられている等、リンク位置を特定できない場合は推測でタップせず手動案内。
- LINEトーク内の案内文だけをクーポン表示完了と誤認しない。取得・表示の記録は操作前に保存し、結果不明でも同じボタンを押し直さない。
- code18の認識0.5秒・探索最大6往復26秒・延長済み待機時間、回答データ、設定の保存先を維持。code15および過去の配布APKを保全。

ユーザーはcode18で、途中停止後に▶を押して第5問へ到達し、計算回答・送信・「クーポンをゲットする」まで成功したと報告。停止履歴の写真には「フロートがスライド領域を覆っています」、別の写真には「クーポンを表示する」が見える状態で待機と表示されている。画像から内部の要素構造は確定できないため、code19の新しいリンク検出・タップは実機確認が必要。

## 試し方

アンインストールせずcode19へ上書き。「第5問・入力テスト設定」はOFFのまま通常の▶再生。||で止めてもフロートが残り、▶で再開できることを確認する。クーポン表示で止まった場合は、アプリの入力診断をコピーしてCOUPON_SELECTED/COUPON_NODE/COUPON_GESTUREの記録を共有する。再生1〜3は引き続き入力だけで送信しない。
