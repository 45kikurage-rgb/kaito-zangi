## 実装

- フロート幅200dp、情報文字12spを維持し、行内に再生・📷・×を配置。📷は先にQuizService.stopを実行し、フロートを隠して非exportedのCameraActivityを開く。起動に失敗すればフロートへ戻して停止。LINEの画面ガードや未確認記録は解除しない。
- CameraX 1.4.2の背面プレビュー＋ImageAnalysis、ML Kit日本語OCR16.0.1のモデルを同梱。写真撮影API、保存先、クリップボード、LINEクリック/入力/送信経路はカメラActivityにない。INTERNETとACCESS_NETWORK_STATEはmanifest mergeで明示的に除去し、最終manifestの権限も検査。
- カメラフレームを約1秒間隔で処理し、処理中の画像を追加投入しない。次は最新フレームを使用し、処理完了時にImageProxyを閉じる。問題文・数値・句読点の完全一致を2回確認（空白・全角だけを正規化、2.5秒以上の確認間隔はリセット）。OCRフレームの取得時刻で判定し、処理に2.5秒以上かかった古い結果は表示しない。
- 1つの第○問だけを要求。第1〜4問はA〜D全要素が読み取れた時だけ既存の50件のAnswerBankへ照合。第5問は問題文の末尾まで読み取れた時だけ既存MathEngineで計算し、答え・形式・検算条件を表示。未登録/条件不明/複数問題は答えを出さない。
- 新問題、空読取、不明な問題、認識エラーでは直ちに前の答えを消す。結果が2.5秒以上途切れた場合も消す。初回はAndroidのカメラ権限確認。拒否・背面カメラなし・カメラ初期化失敗は説明表示。背景へ移動した時は解析/プレビューを解除し、古い非同期結果が再開後の画面を更新しないよう世代番号で拒否。
- 戻ると停止状態でフロートを再表示し、▶を押すまで自動回答しない。カメラを向けた端末には操作を行わず、回答は本人操作。
- Gradle8.10.2/AGP8.7.3へビルドを移行し、依存リソースと初期化manifestをマージ。ラッパー配布物SHA-256を固定。JNIライブラリをAPK内で圧縮し、ダウンロード容量を低減。固定署名・applicationId・既存prefs・アカウント別記録を維持。アイコンの異なるtypeへのaliasを解消し、指定済みの同じPNGとAdaptive Iconを維持。
