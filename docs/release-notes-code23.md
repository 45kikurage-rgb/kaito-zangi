# 怪盗ザンギ code23 実運用版

更新日: 2026-10-14 / versionName 0.1.23 / versionCode 23

通常フロートは再生前72dp、再生後144dpの2倍に変更。停止後も144dpを維持し、内向き矢印で72dpへ戻ります。ヘッダー72dp＋説明文72dpの固定枠です。説明文はスクロール表示から固定枠内の自動文字サイズ調整へ変更し、最大21spで文章全体が収まるサイズを選びます。短い文・長い文・画面幅の変化ごとに再調整します。極端に長い説明は文字が小さくなります。

タイトル・操作ボタン・内向き矢印、クイズとクーポン操作・署名・設定保存は維持。別設定の「第5問・入力テスト」画面は専用ボタンを含む従来360dpのままで、説明文は自動調整します。

code21の動作確認済み報告を基準にした実運用系列の更新です。code23の新しい高さ・文字サイズと上書き更新の実機確認は未実施。公開前に既存回帰チェック・Androidコンパイル・正式署名・APKメタデータを確認します。
