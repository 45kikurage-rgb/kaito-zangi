回答ザンギ 0.1.3-test04 / versionCode 4

- 第1〜4問は問題文の文章だけを取得。文章の意味解析、画像解析、OCR、選択肢本文の正誤判定を行いません。
- 正答表50件それぞれに問題識別キーワードと正答文字A・B・C・Dを登録。必要なキーワードが問題文にすべて含まれる1件を特定し、登録済みの正答ボタンを押します。
- 競歩の「この印」と「このボールが使われるスポーツ」も画像を判定せず、問題文キーワードから正答文字へ直接照合します。
- 提供された競歩画面を再現し、「陸上競技」「競歩」「この印」「意味」からDを選ぶことを確認。
- モルックの助詞差、道具の重さ、ピックルボール／ピックルポールなどの問題文表記差に対応。
- 現在画面から開始し、「もう一度挑戦する」「問題を見る」「次の問題に進む」などのクイズ専用ボタンで進行。
- 再生直後の問題文確認を約1.7秒後に再実行。通常の5秒間隔確認とUI変化イベントも併用します。
- 未知の問題、キーワードが複数問題に一致、必要なA〜Dボタンがない、別画面では停止。通常LINE入力欄・送信ボタンは操作しません。
- 第5問だけは問題形式・数値・条件を抽出して端末内で計算します。
