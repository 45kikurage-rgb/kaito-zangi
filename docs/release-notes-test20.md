# code20 クーポン共有ボタン対応テスト版

2026-10-13 / 0.1.20-test20 / versionCode20 / jp.kossacktouch.app

code19の文字1.5倍、独立した▶再生・||停止・×閉じる、フロートとIMEを避けるスライド、クーポン表示リンク対応を継承。

追加範囲は「クーポンを表示する」→LINE内のクーポンWebView→下部の共有ボタンを1回押す、まで。共有先・受信アプリ・相手は自動選択しない。

- 直前の表示リンク操作記録、同一LINEパッケージ、表示中WebView、その外側かつ画面下部の一意な共有ラベルとクリック可能要素を照合。画像主体のクーポンにも対応するため、本文OCRや商品画像認識は使用しない。
- 0.5秒間隔で2回照合し、押下直前にも再取得する。Web本文の共有リンク、重複候補、非表示要素、大きなコンテナは押さない。固定座標での共有タップは行わない。
- 表示操作から2分を超えた記録、別LINEや別アプリは自動操作しない。通常の表示・共有待機は70秒以内。
- 共有押下前に記録を保存。停止・再開でも押し直さず、共有操作済みと案内する。新しい第1〜4問の表示を確認すれば次のクイズへ進行できる。
- SHARE_SELECTED / SHARE_TOOLBAR / AUTO_SHAREを診断に追加。クーポンURL、バーコード、共有先の個人情報を診断へ記録しない。

## 検証範囲

回帰チェックとAndroidコンパイルを実施。共有ボタンの実機押下・共有先一覧表示・上書き後の設定保持は未確認。ACTION_CLICK成功は共有先一覧の表示成功とは分けて扱う。共有操作の記録を残し、失敗・結果不明での押し直しはしない。
