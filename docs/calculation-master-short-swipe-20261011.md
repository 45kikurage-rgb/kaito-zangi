# 第5問の計算マスターと短距離スワイプ（2026-10-11）

- `app/src/main/assets/final_question_calculation_master.csv` はユーザー提供の33行マスターを同梱（14計算パターン・競技人数10件・ボクシング階級9件）。
- Androidの実行時は従来の `MathEngine` が通信なしで計算する。既存テーブルとCSVが乖離すると `scripts/check-calculation-master.py` が失敗するため、CSVだけを変更しても安全に誤データが使われることはない。
- `CalculationMasterTests` は14パターンの入力文→実計算結果を検査する。未知の文言や丸め条件が曖昧な場合の要確認停止も引き続き有効。
- 必要要素を2回連続で見つけられないときの上スワイプは、画面高さの約10%（LINE操作領域で安全に収まる距離に制限）。下スワイプは従来の操作領域上端から下端まで、回数上限は3往復、時間と登録画面の禁止も維持。
- **第5問の答え表示後、数字入力・送信は本人操作のまま**。署名・版番号・公開APK・ダウンロードページは本変更に含めない。
- 実機で上下方向の取りこぼしとLINE画面復帰を確認してから配布版の更新を判断する。
