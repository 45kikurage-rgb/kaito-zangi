## 2. 実装

- 標準LINEと`jp.naver.line.*`系列の複製LINEを自動候補化。package名入力画面を削除。候補packageだけでは実行せず、唯一の対象トークタイトル・LINE固有のチャット領域/メッセージ構造を併せて確認。
- 操作中のLINE package切替は停止。次の対象トークで再生すると、そのpackageの未確認記録を使用。旧ローカル設定・履歴は保持し、旧記録は安全に移行する。
- 登録の既存情報は変更しない。導入の返信文言を動画に合わせて追加。都道府県と高校は見えているクリック可能な候補のみランダム選択。画面外候補へスクロールしない。折り返した学校名にも対応。
- 生年・性別・規約同意では本人確認として停止し、本人がLINEで選択/同意後に再生。規約を本人に代わって無条件同意しない。
- 第1〜4問の50件の正答表・問題文キーワード照合・A〜Dタップは維持。画像AI・意味解析・メッセージ回答を追加しない。画面チェックは約5秒間隔。
- 第5問はローカル計算。専用フォームを優先。専用フォームがなく、先行する数字回答ガイドを確認できた場合だけLINEの数値入力を許可。左下キーボードボタンで表示し、フォーカス→数値入力→別スナップショットで一致確認→送信を段階処理。
- 入力済みの文字は上書きしない。数字の準備と送信前記録を永続化し、アプリ中断後も再送を防止。専用フォームが不完全な場合に通常LINE送信へ逃がさない。
- 隠れた最終問題ガイド/専用入力欄は上下移動で有限回探索。確認不能、別トーク、ロック、画面OFF、重複/未知の条件では停止。
- 既存指定の格闘家と「？」デザインを使用。Adaptive Iconを追加し、安全領域へ収める。アプリ内ロゴを追加、名称/code表示を統一。サイト説明・アイコン参照・キャッシュを更新。

## 4. 未確認・制約

1. Nothing Phone 2a / CMF Phone 1はこの環境へ接続されていない。APKのインストール・起動・フロート・登録クリック・5問連続完走は実機未検証。
2. 画像だけのリッチメニュー「開始」はUI-treeではクリック領域の意味を取得できない。推測座標を使わず、LINEで開始を1回押してから再生を求める。要素でラベル付き開始を取得できる版のみ自動タップ。
3. LINE入力欄/送信のresource ID対応はテスト版。未一致なら停止し、数字を誤送信しない。実機で停止した場合には、入力欄と送信ボタンを出した状態のUI全走査JSONが必要。
