# 怪盗ザンギ code30 — スライド終端の減速と停止待ち

versionName 0.1.30 / versionCode 30。既存package・正式署名鍵・ユーザー設定を維持します。

## 変更理由と対応

code29で「小さな上スライドのはずが1画面以上動く」という実機報告がありました。原因は未確定ですが、静止したまま保持するだけでは移動イベントが追加されないこと、下方向は利用者の指定どおり高速のまま離す動作を維持し、上方向だけ修正します。

- 上方向の指の移動距離を48dpと画面高さ10%の小さい方に固定。フロート実測高さには依存しません。安全領域が狭い場合はさらに短縮します。
- 上方向だけ、元の移動距離の最後4物理ピクセル（短距離なら半分）を600ms以上・端末最小フリング速度の1/4以下で移動。同じ指を継続し、実際の座標変化を伴う減速を送ります。減速分を含めて指定距離内です。
- 上方向は減速後に300ms保持してから離します。下方向は半画面を150msで高速スライドし、そのまま指を離します。下方向には減速・保持・追加の静止待ちを入れません。
- 減速・保持に失敗した場合は自動処理を停止して指を解放。短い解放を通常成功として次の操作に進めません。
- 上方向で指を離した後600ms以上かつ対象LINEウィンドウのスクロール通知が400ms途絶えるまで次操作を待ちます。2秒以内に停止を確認できない場合は自動処理を停止します。
- 診断へ指の方向・指定距離・減速時間・スクロール通知件数・報告された移動量を記録。本文や学校名は追加しません。通知がない場合、実画面の静止を保証するものではありません。
- 下から探索、上下合計最大10回または26秒、毎回再解析、二重操作防止、学校選択、正答表50問、第5問計算・クーポン処理を維持します。
