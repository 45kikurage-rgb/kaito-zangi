# アイコン制作

提供された動画の赤い衣装の格闘家を参考に、クイズの「？」を砕く正方形アイコンを、組み込みの画像生成機能で制作。元画像は assets/quiz-knockout-icon-master.png。AndroidとPWA向けの512px・192pxは縮小のみを適用しています。

生成指示：参照動画の茶色の髪・ひげ・赤い衣装の格闘家が、青い「？」のタイルを豪快なパンチで砕く。太い輪郭のゲーム風イラスト、濃紺の背景と金色の衝撃、縮小時も判別できる構図。文字や透かしは入れない。
